# hk-petrol-price-crawler
![Data fetching status](https://github.com/hkg-deadline/hk-petrol-price-crawler/actions/workflows/fetch-petrol-price-list.yml/badge.svg)

This project is to fetch the Hong Kong Petrol Price information provided by Consumer Council and convert to a simple JSON format. 
It is hourly synced from data.gov.hk and launched in github pages

## Data Sources
Petrol Price information is provided by Consumer Council through DATA.GOV.HK[https://data.gov.hk].
